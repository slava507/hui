1) Создайте репозиторий на github.com (New repository).
2) Add file -> Upload files: перетащите ВСЁ содержимое этой папки (www, .github, package.json, capacitor.config.json). Commit.
3) Вкладка Actions -> дождитесь зелёной галочки (5-10 мин) -> откройте запуск -> внизу Artifacts -> planner-apk -> скачайте, распакуйте, получите app-debug.apk.
4) Отправьте apk на телефон, откройте, разрешите установку из неизвестных источников.
